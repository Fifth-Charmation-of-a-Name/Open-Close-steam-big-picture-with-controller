# Open And Close Steam Big Picture With Controller's Guide Button

A small background utility for Windows that lets you open and close Steam
Big Picture mode using your Xbox controller's Guide button — no need to
reach for a keyboard or mouse.

## What it does

- **Double-press** the Guide (Xbox) button → opens Steam Big Picture mode
- **Triple-press** the Guide button → closes Big Picture and minimizes Steam
  to the system tray
- A single press does nothing, so it won't interfere with normal use of the
  button
- Each action gives a distinct rumble pulse on the controller, so you get
  confirmation without looking at the screen

## How to use it

1. Download `Big_Picture_Launcher.exe`.
2. Run it. It runs silently in the background with no window or console.
3. With your Xbox controller connected, double-press the Guide button to
   open Big Picture, or triple-press it to close it.

That's it — no installation or setup required.

**Optional:** if you want it to start automatically every time you log in,
add it to Task Scheduler with a trigger of "At log on."
