# Open Steam Big Picture With Controller's Guide Button

A background utility for Windows that lets you open and close Steam
Big Picture mode using your Xbox controller's Guide button

## What it does

- **Double-press** the Xbox button → opens Steam Big Picture mode
- **Triple-press** the Xbox button → closes Big Picture
- A single press does nothing
- Each action has haptic feedback   

## How to use it

1. Download the exe
2. Run it
3. It runs in the background
4. With your Xbox controller connected, double-press the Guide button to
   open Big Picture, or triple-press it to close it

**Optional:** You can set it to launch automatically with Task Scheduler
